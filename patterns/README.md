## ⚡ Complexity Understanding

### 🔤 Frequency Count Pattern:
- Time: O(n)  
- Space: O(n) or O(1) (if fixed size array)

---

### 🔢 HashMap Pattern:
- Time: O(n)  
- Space: O(n)  

👉 Used when:
- Fast lookup is needed  
- Searching for complements (e.g., `target - value`)  

---

## 🔥 Pattern Recognition Tips

### 🟡 Frequency Count
If you see:
- “same characters”
- “same frequency”

👉 Think **Frequency Count**

---

### 🟢 HashMap
If you see:
- “find pair”
- “target sum”
- “lookup quickly”

👉 Think **HashMap**
